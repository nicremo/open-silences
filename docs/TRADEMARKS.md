# Project naming

Product name: **Open Silences**. Repository name: `open-silences`. Maintainer: Fabian Bitzer.

Descriptions focus on the project's own function: local silence removal for Adobe Premiere Pro, a Rust engine, sequence backups and a two-step workflow.

Adobe and Premiere Pro identify the host application. The project is not affiliated with or endorsed by Adobe. Do not use Adobe logos as project branding or imply an official partnership.

A short web search on 2026-10-08 did not identify a matching Premiere product named Open Silences. This was not a trademark-register search and is not a formal clearance of the name.
